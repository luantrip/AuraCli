# Founder playbooks

These playbooks define native workflow boundaries. Each phase consumes only the
artifacts it needs and writes a reviewable result under the project artifact
directory.

- `board`: assumptions, risks, conditions and decision.
- `competitors`: sourced alternatives, prices and complaints.
- `consumer`: profile, pitch, sampled objections and buy rate.
- `pricing`: price answers, sensitivity and test price.
- `offer`: objection-to-offer mapping and re-test.
- `cfo`: contribution, break-even, cash and scenarios.
- `marketing`: positioning, channels and dated experiment.
- `brand`: naming, promise, voice and verification checks.
- `ops`: suppliers, routines, permits and risks to verify.
- `launch`: cheap validation test, countdown and first 30 days.
- `plan`: evidence-backed summary and computed verdict.
